#  Passa a Bola

Uma plataforma web dedicada ao futebol feminino brasileiro, desenvolvida para conectar torcedoras, jogadoras e apaixonados pelo esporte em um único ambiente digital.

##  Sobre o Projeto

O Passa a Bola foi criado com o objetivo de ampliar a visibilidade do futebol feminino por meio de conteúdo informativo, interação entre usuários e acesso facilitado a informações sobre equipes, campeonatos e notícias do cenário esportivo.

A plataforma reúne recursos voltados para a comunidade do futebol feminino, oferecendo uma experiência moderna, intuitiva e responsiva.

##  Funcionalidades

-  Portal de notícias sobre futebol feminino
-  Visualização de times e competições
-  Acompanhamento de jogos e resultados
-  Área de torneios e chaveamentos
-  Espaço para comunidade e interação
-  Divulgação de conteúdos do podcast Fala, Bebê
-  Interface responsiva para desktop e dispositivos móveis

##  Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git
- GitHub Pages
